React Pricing Cards UI

A modern and responsive Pricing Cards UI built using **React.js, JavaScript, HTML, and CSS**.

This project displays multiple pricing plans with their respective prices and features in a clean, attractive, and user-friendly interface.

## ✨ Features

- 🎨 Modern and clean UI design
- 💳 Multiple pricing plans
- ✅ Available and unavailable feature indicators
- ⚛️ Reusable React components
- 📱 Responsive layout
- 🔄 Dynamic rendering using JavaScript `map()`
- 🧩 Component-based architecture

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- npm

## 🚀 Getting Started

### 1. Clone the Repository

git clone https://github.com/JayaJavaDev/React-pricing-cards-UI.git

### 2. Navigate to Project Folder


cd React-pricing-cards-UI

### 3. Install Dependencies


npm install


### 4. Run the Development Server

npm run dev


Open the local URL displayed in your terminal to view the application.
